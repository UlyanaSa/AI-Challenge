Вопросы набора не редактируются: вместе с каждым заранее известен ответ, ключевые факты и место в книге — по ним и считается оценка. Индекс базы строится один раз: поиск идёт по готовому файлу, и в шапке видно, был он собран заново или взят готовым.

    2 Десять контрольных вопросов

    Каждый вопрос прогоняется дважды: сначала агент без базы — он отвечает по памяти, потом агент с базой — он отвечает по найденным фрагментам. Оценка 0–2 у обоих одна: 0 — ответа нет или он неверен, 1 — часть ожидаемых фактов, 2 — все. «Источник» — попал ли ожидаемый текст в Top-K: это отдельная проверка поиска, она не входит в оценку ответа и отделяет ошибку поиска от ошибки генерации.
