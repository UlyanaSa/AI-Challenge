Загрузка корпуса…

1 Загрузите PDF

Документ дня уже на месте: это встроенный PDF, и в корпус входят не все его страницы, а отрезок вокруг ответа — диапазон виден в списке файлов ниже. Текст, страницы и заголовки берутся из самой вёрстки файла. Этот шаг можно пропустить и сразу перейти ко второму; он нужен, если хочется добавить свой PDF рядом. Загруженный документ ложится в рабочий каталог и переживает перезапуск страницы.

      3 Запустите поиск вопроса дня

      Вопрос задан заранее и не редактируется: вместе с ним заранее известно, где лежит ответ, — это страницы загруженного PDF, и текст ответа читается оттуда же. Человек выбирает только top_k: сколько результатов показать.

      Обе стратегии получают один и тот же вопрос: расхождение в выдаче — след нарезки, а не поиска. Значок эталон отмечает чанк, который лежит на страницах эталона.
